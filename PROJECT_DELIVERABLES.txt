COMMAND REPLACEMENTS
════════════════════════════════════════════════════════════════════════════════

Arch/Pacman                  →  Chisel
─────────────────────────────────────────────────
pacstrap                     →  chisel install
pacman -Syy                  →  chisel sync
pacman -Q                    →  chisel list
pacman -Ql                   →  /kod/store/ check
pacman -Sgq                  →  chisel search
pacman -Si                   →  chisel info / registry.json
pacman -S --needed           →  chisel install
